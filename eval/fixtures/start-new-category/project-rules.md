# Project Rules

<!-- A substantive, customised rules file. It homes the categories that already
     exist — it says nothing about a category a later phase introduces. -->

## Naming

- Source files use `snake_case`; exported symbols use `PascalCase`.
- Test files sit beside their subject as `<name>_test`.

## Code samples

- Each code sample lives in `examples/samples/<feature>/` and is named after the
  feature it demonstrates.
- Every sample opens with a one-line comment stating what it demonstrates.

## Accessibility

- Every interactive control has an accessible label.
- Colour is never the sole carrier of meaning.
