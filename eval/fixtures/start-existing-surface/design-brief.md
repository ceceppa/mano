# Design Brief — Example Gallery

## Visual Direction

- **Style:** Clean documentation gallery
- **Mode:** Light
- **Accessibility target:** WCAG 2.1 AA

## Colour Palette

| Role | Colour | Hex |
|------|--------|-----|
| Primary | Gallery blue | `#1F5FD0` |
| Background | Paper | `#FAFAFB` |
| Text | Ink | `#141A24` |

## Components

- **Category selector:** two tabs, side by side, full width of the list column.
  The active tab carries the primary colour underline; the inactive tab is ink
  at 60% opacity.
- **Example card:** title, one-line summary, thumbnail.

The selector is specified as a two-tab control. Hierarchy, spacing, and active
treatment for any further category are not covered.
