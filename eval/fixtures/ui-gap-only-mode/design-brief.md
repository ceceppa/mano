# Design Brief — Preview Service

## Palette

| Token | Value | Use |
|---|---|---|
| `surface` | #FFFFFF | Panel and card backgrounds |
| `border` | #E2E2E2 | Dividers and card outlines |
| `text-primary` | #1A1A1A | Body and headings |
| `text-secondary` | #6B6B6B | Supporting copy |

## Components

- **Thumbnail card** — a `surface` tile with a 1px `border`, 8px radius, and a `text-secondary` caption beneath the image.
- **Panel header** — a full-width `surface` bar with a `border` bottom divider and 16px padding.
