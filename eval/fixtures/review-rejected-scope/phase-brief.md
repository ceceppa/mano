# Phase Brief — Panel Dock — Phase 2

## Phase Goal

The four editor panels live in a dock the user can arrange, so the workspace fits the task at hand.

## Phase Scope

- The docked panel container holding the four editor panels.

## Exit Criteria

1. Panel dock shell
   - The four editor panels appear inside the dock.

## Assumption Log

1. Users want to arrange panels themselves rather than switch between fixed layouts.
2. The dock is the right long-term home for the editor panels.
