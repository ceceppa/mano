# Phase Brief — Tag Index — Phase 1

## Why This Phase

Notes already exist but nothing groups them, so a reader cannot find everything on one topic without scrolling the whole list.

## Phase Goal

A reader can tag a note and open one tag to see every note carrying it.

## Phase Scope

1. **Tagging**
   a. **Attach a tag** — a reader puts one or more tags on a note and sees them on it
   b. **Remove a tag** — a reader takes a tag off a note and it stops appearing there

## Not This Phase

- Renaming or merging tags, tag colours, and any tag suggestion or autocomplete.

## Exit Criteria

1. **Tagging**
   a. Tag a note `recipes` then reopen the note: the tag `recipes` is still on it
   b. Remove the tag `recipes` from that note then reopen it: no tag is shown

## Validation Plan

### Questions

- **Q1.** Is one flat tag per note enough, or do readers immediately want nesting?

### Try

- Tag a week of real notes and open the three busiest tags — watch whether you reach for a sub-tag

## Assumption Log

| ID | Assumption | Risk if wrong |
|---|---|---|
| A1 | Readers tag as they write rather than in a separate tidy-up pass. | Tagging is never done, and the index stays empty. |

## Acknowledged Risks

- None.
