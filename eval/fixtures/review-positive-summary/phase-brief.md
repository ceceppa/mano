# Phase Brief — Notes — Phase 1

## Phase Goal

A reader can save one note and find it in the note list.

## Phase Scope

- Save one note.
- Show saved notes in the note list.

## Exit Criteria

1. Save a note
   - The reader saves `Bread`: `Bread` appears in the note list.

## Assumption Log

| Assumption | Risk if wrong |
|---|---|
| One Save button gives the reader enough control for this phase. | The save flow may need another action. |
