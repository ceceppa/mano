# post-import hook

## Mode
check

## Inputs
- `_mano_output/backlog.md`
- the source document `mano import` ran against, if still available

## Checklist
- Every feature, requirement, and success criterion in the source appears as a backlog item.
- Items preserve the source's specific detail — no lossy summaries.
- No duplicate or overlapping items.
- Core Product Principles are captured accurately, not invented.
- Any stated technical preference is preserved verbatim in item context, not decided.
